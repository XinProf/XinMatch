# Refill Peak Residuals

## Rescale Peak Intensities
If the Residual searching option on the Search-Match
page of the Options-dialog is
active, the available relative peak intensities are reduced each time a phase is selected as
matching, by subtracting the corresponding relative peak intensity values of the phase from
the experimental peak intensities.
By running the Refill residuals command from the Peaks menu you can restore the
original available relative intensities to their full values again.
