# Selection of Reference Pattern Database

## Selection of Reference Pattern Database
You can easily switch between several reference databases in the "Reference
Database Library" dialog: In order to select another existing reference database for being used in future
search-match and restrainting operations, please mark (click on) the corresponding
line in the Reference Database Library. Afterwards, press the "Select" button at
the bottom of the dialog.
If the selected reference database is an ICDD PDF-5+, PDF-4 or PDF-2 database, the validity of the licence will be checked. Afterwards, the reference
database will be marked as selected, indicated by the ">>>" arrow on the left-hand
side of the corresponding line.
You can now leave the Reference Database Library by pressing "Quit" and apply
the selected reference database in phase analysis and database retrievals.
Please note:
- If you select a different reference database while your candidate list contains entries and/or if you have entered any selection criteria, the candidate list will be updated using the new
reference database.
- The name of the currently selected reference database is displayed in the status
bar at the bottom of the "Match!" window. This name is updated when the Reference Database Library is closed.
