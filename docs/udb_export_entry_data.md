# Export Entry Data from User Database

## Export Entry Data from User Database
You can export the complete contents (e.g. diffraction pattern and crystal structure data) of one
or more user database entries into CIF- or txt-file(s), e.g. in order to use the crystal structure data
in a Rietveld refinement.
Please make sure that the corresponding entries are marked
in the Entry list of the User Database Manager, then press the "Export"
button at the top of the window. A new window will open in which you can select the directory and file name
for the export. At the bottom of this new window, you can choose between the file formats "CIF file (*.cif)" or "Text file (*.txt)".
Please note:
- It is also possible to export entry data directly from the candidate list in the main window of
Match!.
