# Export Refined Crystal Structure

## Export Refined Crystal Structure
Once you have run a successful Rietveld refinement
calculation,
you can export the resulting crystal structure data of a certain entry/phase to a CIF-file.
You can do so only for a single Match list entry at a time.
Please make sure that the entry for which you would like to export the refined crystal structure of
is marked in the Match list, then
select the "Refined structure" command from the "File/Export" submenu.
A new window will open in which you can select the directory and file name for the export.
Note:
- The "File/Export/Refined structure" is only available if a single entry is marked in the
Match list.
- This command is also available from the Match list context menu.
