## 1. 项目概况

### 1.1 一句话定位

**XinMatch** 是一个开源的粉末 X 射线衍射（XRPD）物相分析平台，对标商业软件，采用净室实现（clean-room）策略——只参考公开文档与已发表算法，不反编译、不复用专有代码。数据基础是 CC0 公共领域的 [COD](https://www.crystallography.net/cod/) 数据库。

### 1.2 功能边界（2026-10-13 现状）

| 类别 | 功能 | 状态 |
|---|---|---|
| **定性** | 物相鉴定（Search-Match）：**峰列表 FoM**（寻峰+相关+5 分量加权）与 **SMPF 全谱拟合**（不寻峰、全谱 Rwp 精排）双模式，GUI 统一入口切换 | ✅ 生产可用（v1.4 起 SMPF 支持 Caglioti 角度依赖宽化 + 晶胞微调） |

### 1.3 架构原则（不变）

1. **Kernel / GUI 解耦**：`xinmatch/core/` 纯计算（numpy + dataclass），无 GUI 依赖；`xinmatch/ui/` 是薄层。
2. **净室实现**：规格来自公开文档 + 已发表算法 + 黑箱文件格式观察。
3. **开放数据**：参考库基于 COD（CC0）。
4. **精修外包**：Le Bail / Rietveld / 残差 / 峰形 / 结构因子 / 策略化精修**全部委托 GSAS-II**；XinMatch 只做项目构造 + 参数暴露 + 结果解析 + GUI 交互。
5. **SMPF 定位**：SMPF 负责"**先找到相**"，逐晶胞/结构因子级精修交给 GSAS-II——本次 SMPF 扩展按此定位取舍（见 §4.2）。
6. **品牌红线**：全仓（代码/文档/About/打包资源/提交信息）不出现对标商业软件名称，统一用「参考软件」中性表述；grep 自检 0 命中。

## 4. 已完成进展（2026-10-12 之后的增量）

### 4.1 无机库构建逻辑排查专项（#14，commit `62909cd`）

**问题**：教科书物相（岩盐 Halite / 钾盐 Sylvite / 方镁石 Periclase / 黑铜矿 CuO）系统性检索不到。

**结论：三层缺陷叠加**，任何单层修复都不够（详见 `docs/STATUS.md` v1.4.0 章节）：

| 层 | 缺陷 | 修复 | 效果 |
|---|---|---|---|
| A 峰表污染 | Kα2 剥离自激振荡（Rachinger 递归对无卫星谱模型失配，振荡达峰高 50%） | `alpha2.py` 负偏移护栏（超峰值 1% 即跳过剥离） | 合成 NaCl 谱 43 峰 → 5 峰 |
| A | MAD 噪声估计崩塌（背底相减后平坦区一阶差分恒 0 → 阈值≈0.02） | `peak_search.py` 信号相对下限 `noise ≥ 1e-3·signal` | SNIP 残留阶段 13 → 5 峰 |
| A | 突出度语义缺陷（Kα2 护栏上线后暴露）：8×FWHM 截断 Lorentz 尾留 40–160 计数"尾毯"，其上噪声凸点越阈 | 钥匙鞍点突出度 + 候选吸附局部极大 + 宽度自适应半窗 | synth_06 182 → 122 峰，BaTiO₃ 回 Top-5 |
| B 库数据 | 上游 dump 无纯二元条目；库内卡片为非环境条件变体；10 张强度未归一化；52,366 幻影峰 | `tools/patch_cod_inorganics.py` 幂等迁移（3 张环境条件卡片现算插入 + 归一化 + 清幻影峰 + 备份） | 已验证幂等（二次运行 0 修改） |
| C 召回 | 稀疏谱下密集卡片计数打平，按 entry_id 字典序截断，`96-900-xxxx` 恒被挤出 | `recall_strongest_peak` 默认翻转 True（Hanawalt） | 13 组合成谱 8/13 → **13/13** |

**教科书三相探针结果**：Halite rank 1（FoM 0.928）/ Sylvite rank 5 / Periclase rank 2（榜首为掺 Fe 近缘卡片 `Fe0.01Mg0.99O`，合理）。

### 4.2 SMPF 剩余扩展（#15，commit `d6a543c`）

**背景**：`docs/smpf_mechanism.md` §8 列了四项局限。本次**先做数据可行性核查再定范围**——这一步直接改变了结论：

- 实测 `cod_inorganics.db` 的 `peaks.h/k/l` **6,214,072 行全为 NULL**（`Entry.hkl` 恒 None）→ **March-Dollase 择优取向被数据阻塞**；
- `entries.a/b/c` 仅 15/71206 缺失 → 晶胞微调成立。

| 局限项 | 结论 | 依据 |
|---|---|---|
| FWHM 全局单值 | ✅ 实现 Caglioti U/V/W（默认开） | 不依赖 hkl；合成谱生成器同款模型可验证参数回收 |
| 晶胞微调 | ✅ 实现 `cell_delta`（默认开，±0.5%） | 2θ 位移 ∝ tanθ，与常数 shift 签名不共线 ⇒ 可识别 |
| 择优取向（March-Dollase） | ⛔ **被数据阻塞** | 需逐反射 hkl 算面法向夹角，须先做 CIF→hkl 回填（§5.2） |
| 峰形不对称 | ⏸ 明确推迟 | η 自 v1.2 起就在拟合向量内，已吸收一阶不对称 |
| 多相解叠 | ⏸ 明确推迟 | SMPF 定位是"先找到相"；混合谱真相相仍可 Top-1，仅 Rwp 偏高 |

**实现要点**（`xinmatch/core/search/smpf.py`）：

1. `_caglioti_fwhm`：`H²=U·tan²θ+V·tanθ+W`，H² 先夹 0 再开方（否则 NaN），H 再夹进 `fwhm_bounds`；
2. `cell_delta`：2θ 位移 `−Δ·(360/π)·tanθ_i`（Bragg 一阶，Δ=0.005 时二阶误差 <0.001°）；开启时按 `cell_bound·(360/π)·tanθ_i` **逐反射加宽评估窗**，防峰被推出窗截断；
3. 参数向量 7→11 按 `cfg.caglioti` / `cfg.cell_refine` 动态组装，关闭时严格回退 v1.2；score_dict 新增 `caglioti_u/v/w`、`cell_delta`（关闭时为恒等编码）；
4. **剖面向量化**：逐反射切片循环 → 统一宽度索引矩阵 + `np.bincount` 累加。

**性能（本次最反直觉的一点）**：参数 7→11 首版精排慢 2.8×（refine 12.5→34.7s，照此外推会破 120s 护栏）。插桩定位 = nfev 7→8.9（1.27×）+ 单次残差 4.4→6.8ms（1.55×），后者源于**逐反射循环里 8 次小数组 numpy 调用的固定开销**。向量化后单次残差 0.42→0.18ms，**端到端反比 v1.3 更快**：

| 谱 | v1.3 | v1.4 | 变化 |
|---|---:|---:|---|
| synth_01 | 44.8s | 43.4s | −1.4s |
| synth_06 | 57.2s | 51.1s | −6.1s |
| synth_12 | 40.2s | 36.1s | −4.1s |
| synth_13 | 68.3s | 61.5s | −6.8s |
| 2-1（真实） | 89.9s | 80.1s | −9.8s |
| 5-2b（真实） | 108.3s | 90.3s | −18.0s |

6 谱真相相全部保持 Top-1；真实谱 Rwp 微降（2-1 0.4439→0.4421、5-2b 0.4176→0.4170）。**合成谱 Rwp 基本不变**——生成器用的是**带下限**的 Caglioti（H 全程 <0.15° 下限 ⇒ 实际常数宽度），两种模型在合成集上不可区分，收益只体现在真实谱。

## 6. 经验教训（2026-10-13 新增，承接 HANDOVER-20261012 §6.1 编号）

16. **先查数据填充率，再选物理模型**：`Entry` 有 `hkl` 字段 ≠ 库里有 hkl 数据——实测 `peaks.h/k/l` **6,214,072 行全 NULL**，`Entry.hkl` 恒 None，March-Dollase 直接出局；`entries.a/b/c` 仅 15/71206 缺失，晶胞微调才成立。**模型能力受限于 DB 字段填充率，不受限于数据类的字段定义**——选型前先跑一条 `COUNT/SUM(CASE WHEN ... IS NOT NULL)` 探针。
17. **加了参数反而可能更快，瓶颈常在别处**：参数 7→11 首版慢 2.8×；插桩拆分为 nfev（1.27×）与单次残差（1.55×）后定位到**逐反射循环里小数组 numpy 调用的固定开销**。改向量化后单次残差 0.42→0.18ms，端到端反比 v1.3 快。**先分别量 nfev 与单次残差，别急着动 `max_nfev`**，也别凭直觉猜开销来源。
18. **向量化改动的等价性要可复现地验证**：改前 `cp` 旧文件到 `.scratch/`，用 `importlib.util.spec_from_file_location` 以独立模块名加载旧实现，逐配置对比（Kα 双线 / 晶胞偏移 / 窗口加宽 / 0.01 与 0.02 网格 = 48 组）`max|Δ|/max < 1e-12`。
19. **物理扩展的收益要看"数据生成路径"，验收集能证伪不等于能证实**：生成器用**带下限**的 Caglioti ⇒ 合成集上两模型不可区分（Rwp 差 <0.001）；生成器的 `_march_factor` 乘的是**峰内形状**（窗内 |Δ2θ| ≤ 0.028 rad，cos≈1，近似常数 1.52）被 `scale` 吸收，**不是**真 March-Dollase。
20. **新增几何参数前先确认它与既有参数的角度签名不共线**：晶胞缩放 2θ 位移 ∝ tanθ vs 常数 shift ⇒ 可识别（人工 Δ=+0.003 谱：开启 Rwp 0.0063 / 关闭 0.0640，差 10×）。若签名共线（窄角区 tanθ 几乎相同），新增参数只会退化成噪声放大器。
21. **本环境判定 pytest 结论的正确姿势（重要）**：pytest 收尾会被沙盒钩子拦截临时目录清理（>50 文件阈值）→ **汇总行不落盘、退出码非 0**，极易误判为失败。**必须以 `--junitxml` 计数或进度行里的 F/E 字符为准**。另：PowerShell 输出末尾的 `X` 是终端渲染字符，不是 pytest 失败标记。
22. **两个 Python 运行时分工**：托管 venv（3.13.14 / numpy 2.5.3 / scipy 1.18.1 / pytest 9.1.1）跑核心测试；**UI 测试必须用 `D:\Project\XRD\python310\python.exe`**（venv 无 PySide6）。`tests/db/test_pdf2_source_config.py` 在两环境下均收集失败，属既有问题。
