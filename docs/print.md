# Printing

## Printing
You can print any view of the Match! screen (report, candidate list, data sheet, peak list,
diffraction pattern) by selecting the "Print..." command from the "File" menu.
Alternatively, you can also click on the corresponding button
in the main toolbar (right below the menu), or by pressing <Ctrl+P> on the keyboard.
In any case, the "Print" dialog will be opened in which you can select which view you would like
to print. Afterwards, simply press "OK". The standard printer dialog will appear in which
you can e.g. select the printer you would like to use, or modify the printer's settings. Once
you close this dialog by pressing "OK", your selected view will be printed.
In addition to the procedure just described, the report can also
be printed by including the corresponding option in the "Finish" command, or directly from the report window.
