# Finishing Tasks

## Finishing Tasks
Once the matching phases have been selected, there are typically some routine tasks left in order to really finish the phase analysis, like e.g. the printing of the report. Match! provides a special command to run a "batch" of these finishing tasks. You can define which task shall actually be carried out on the "Batch"-page of the "Options" dialog.
You can run then "finishing tasks" batch either using the  button in the main toolbar at the top, by pressing the combination <Ctrl+W> on your keyboard (<Cmd+W> on the Mac), or by executing the "Finish" command in the "File" menu.
The following tasks can be included in the batch process:
- Print the report
- Save residual peaks
- Save session
- Quit Match!
Note: Of course, you don't have to use the "Finish" command and options if you don't like; you can also perform the corresponding tasks on your own !
