# Rescale Peak Intensities

## Rescale Peak Intensities
In order to rescale the relative peak intensities to a maximum value of 1000.0,
please run the
Scale relative intensities command from the Peaks menu. This may e.g. be appropriate if you
have entered peak data using the mouse, in which case the peak intensity values correspond to
the integrated peak intensities, with their maximum value being below 1000.0 (even though the profile data
maximum intensity value is 1000.0).
