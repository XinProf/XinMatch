# Save User Database Entry

## Save User Database Entry
Once you finished editing an entry, the data still have to be saved to the database. In order to do so, please click the "Save changes" button at the bottom of the user database manager; your entry will now appear in the entry list at the top.
Note: You should always keep in mind that any modifications in the user database manager only affect the temporary copy of the user database, as long as the modified user database has not yet been activated (i.e. saved to a file)!
