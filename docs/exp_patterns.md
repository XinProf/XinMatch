# Experimental Diffraction Pattern Table

## Experimental Diffraction Pattern Table
Using the menu command "Pattern / Experimental patterns..." (or by pressing the corresponding button
in the main toolbar at the top)
you can display a table of all currently loaded experimental diffraction patterns, along with
options to display / edit their sample ID, date/time, temperature, color, line style, data point symbol etc..

- This command replaces the "Additional patterns" sub-menu at the bottom of the "Pattern" menu that was
available in earlier versions of Match!.
