## 三、为什么这次验收比较费时间（按耗时排序）

1. **参考软件口径黑盒**（最大头）：xlsx 是 stdlib zip+xml 手工解析（venv 无 openpyxl）；docx 是 zip+正则提文本；且表 4（MAUD Rietveld 18/36%）在文档中截断，需从相邻表推断并标注缺失——每步都要重读原始文件核数，不能抄摘要。
2. **两套定量口径的调试**：先试文献 RIR（低估 2 倍）→ 判定必须改为同仪器标定 → 重写标定链路。API 签名踩坑 4 处（`smooth(order=→polyorder=)`、`estimate_background(n_points→window)`、`subtract_background` 两参数、`find_peaks(prominence→sensitivity)`+Peak 对象属性）——均为只读源码核对，一次定位。
3. **PowerShell 多行 `-c` 转义反复失败**：内联脚本的中文路径/引号被吞 → 改脚本文件方案，含一次误把 Path 当 Pattern 传参（AttributeError）修复。
4. **数值核验**：全谱 vs 局部谱双路径、三样品 × 两方法参考、重复性差——共 12 组数交叉核对，含 1 处文档污染字符修正。
