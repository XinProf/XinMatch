# Export of Diffraction Data (Peaks)

## Export of Diffraction Data (Peaks)
In the User Database Manager, you can export the diffraction pattern
of the entry currently marked in the Entry list. This can e.g. be appropriate if the diffraction pattern has
been calculated from crystal structure data and you would like to keep it for reference. Currently, only
the Endeavour peak list file format (2 columns:
d-value intensity; *.dif) is supported as export format.
If you would like to export the diffraction pattern of the entry currently marked in the entry list, please
click on the header of the "Diffraction pattern" tabsheet to bring it into front. Afterwards, click on the
"Export" button to the left of the peak data table. A dialog will open in which you have to select the
directory and enter the name for the diffraction data file you would like to export your data to.
Once you have done this, please press "Save". A message will appear that your diffraction data have
been exported successfully.
