# Exporting the Report

## Exporting the Report
You can export the current report to one of the following file formats:
- PDF (*.pdf)
- HTML (*.htm)
- Text file (*.txt)
If it is not currently displayed, please open the report by selecting the corresponding command from the "View" menu (or press <Ctrl+R> (<Cmd+R> on the Mac)). Afterwards, press the "Save" button at the bottom of the report, select the desired "Files of type" option at the bottom, then enter the file name and click "Save".
