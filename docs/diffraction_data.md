# Diffraction Data

## Diffraction Data
In the panel on the upper left-hand side of the Match! window, the diffraction data are displayed graphically. Besides this, a lot of additional information (like peak correlations) can be displayed as well. Details are given in the diffraction pattern basics.
You can also use the diffraction pattern to inspect the diffraction data in detail (using the zoom and/or track facilities), or to edit the peaks of the unknown sample's diffraction pattern.
Finally, you can exclude one or even more areas of the diffraction pattern from the figure-of-merit calculation.
