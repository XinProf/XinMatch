# Profile Area Integrated Intensity Calculation

## Profile Area Integrated Intensity Calculation
You can instruct Match! to calculate the intensity integrals of various profile areas by selecting the
Calculate profile integrals... command from the Quantify menu.
A new dialog will open and display a table of the following different profile areas:
- Overall diffraction profile
- Background radiation
- Diffraction peaks
- peak area belonging to selected phases
- peak area belonging to each individual selected phase
- Unidentified peak area
For each profile area, the integrated counts as well as the relative amount
is given.
The profile integrals are also given at the bottom of the match list
as well as the report.
