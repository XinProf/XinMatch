# Add Entry to User Database

## Add Entry to User Database
The probably most flexible (but also the most tiresome) way to add entries to your user database is to
enter them manually in the User Database Manager. In many cases
this is the only applicable way, if e.g. the data exist only as a printed publication.
Start by clicking on the "Add" button at the top of the User Database Manager. The "General" tabsheet will be
activated automatically, with the cursor in the first
input field "Sample name". Afterwards, please enter your data on the appropriate tabsheets following the guidelines given
for the modification of entries.
