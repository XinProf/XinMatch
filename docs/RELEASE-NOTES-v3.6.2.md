## XinMatch v3.6.2 — 谱图区交互改造（参考线分区 / 快捷图标 / 轴点击切换）

> 基线 `v3.6.1`（源码 `272539d`）｜本版是**界面交互**版本：无 `core.*` 接口变更、
> 无 `.xinDB` / `.xinm` / `config.yaml` 格式变更、FoM 权重与检索默认行为逐项不变，
> 基准数字与 v3.6.1 完全一致。
>
> v3.6.1 的安装包**已构建但未人工验收、未打 tag、未发布**；本版在其之上改了谱图区，
> 两者的二进制互不覆盖：`dist/` 里的 3.6.1 产物**不含**本版功能。

### 一、要解决的问题

用户在真实使用中提出的四条（原文见 STATUS §v3.6.2）：

1. 「在谱图下方，当候选列表选择一个物相时，上面显示对应的位置和强度……以便使用人员
   比对物相匹配情况，可以鼠标在这个区域勾选只要角度位置或同时显示角度和强度」
2. 「右侧已匹配的物相，也在这个区域都显示上吧……以便查漏是否有峰未匹配」
3. 「谱图的这个区域可以不用要（隐藏，但功能保留），把功能放入横竖轴中，鼠标点击左键
   可切换不同的显示，鼠标右键也可以切换」
4. 「这个位置可以参考 XinRefinement 那样显示一些快捷图标以便对谱图进行处理」

### 二、做了什么

#### ① 谱图下方的「参考线分区」（`xinmatch/ui/stick_lane.py`）

一行一个物相：左侧标签（默认取化学式，如 `MgCO3`），行内竖线从行基线向上生长，
**横坐标与主谱图共用**（`ViewBox.setXLink`），所以竖线正上方就是谱图里对应的峰。

| 项 | 内容 |
|---|---|
| 两种模式 | 勾选「同时显示峰强」（默认）：竖线高度 = 行内归一化的相对强度；取消勾选：全部等高，只看角度位置 |
| 行标签 | 贴着视场左边缘，带半透明主题底色（压在竖线上仍可读）；平移/缩放时跟着走 |
| 行分隔 | 每行边界一条淡色 `InfiniteLine`（取 `theme.THEMES[current]["chart_grid"]`） |
| 空态 | 无行时整个分区 `setVisible(False)`，谱图自动吃掉这块高度 |

**横坐标对齐**是这里最容易做错的地方：分区藏在主谱图下方，两块 `ViewBox` 的左内边距
（左轴宽度）只要差 1 px，竖线就会整体错位。实现上做两件事——

1. `sync_geometry()` 把分区的左轴 `fixedWidth` 同步成主谱图左轴的**当前像素宽度**
   （不是猜一个常量）；窗口 resize、数据变化、行变化、主题切换时都调用；
2. 同步之后由 pyqtgraph 的 `linkedViewChanged` 按**屏幕几何重叠区**做补偿
   （`ViewBox.py:1075-1100`），把两块视图的重叠像素列对齐。

回归测试用 `mapViewToScene()` 直接比对"同一个 2θ 在两块视图里的像素 x"，容差 1.5 px。

#### ② 候选相预览行 + 已确认相全部入区

| 触发 | 表现 |
|---|---|
| 候选列表**高亮**某行 | 分区顶部出现该相的**虚线**预览行（橙色，标注「候选 ⟨化学式⟩」） |
| 双击 / 回车 / 「确认该相」 | 该相转入已确认列表，预览行消失、正规行出现（实线） |
| 撤销 / 清空匹配列表 | 分区跟着少行 / 清空 |
| 换数据 / 换一批候选 | 预览行清空（`set_candidates()` 显式发空 `candidate_highlighted`） |

- 新增信号 `CandidateListTable.candidate_highlighted(str)`（条目号，无选中时为空串）；
  `currentRowChanged` 驱动，`set_candidates()` 里额外显式清一次——模型 reset 会清当前行，
  但**未必**发 `currentRowChanged`。
- 颜色即身份：分区行与主谱图里叠加的参考线条（`_rebuild_reference_sticks`）按**同一
  索引**取 `PATTERN_COLORS`，同一相两处颜色一致（有回归测试钉住）。
- 行内强度**归一化**：主谱图参考线的高度是「比例因子 × 相对强度」（它**声称**贡献的
  计数，可与实测峰比高低）；分区的高度是「行内最强线占满行高」（只回答"哪几条是强线"）。
  两者语义不同，故意不共用数值。

#### ③ 顶部轴控制条隐藏，改成点击坐标轴切换

- `PatternPanel._axis_bar`（X 轴下拉 / Y 轴下拉 / 适应数据范围）**隐藏**，但
  `x_combo` / `y_combo` / `fit_button` 三个属性**保留且仍可用**——下拉框依旧是轴模式的
  唯一真相源（轴的点击最终也是改它们的 `currentIndex`），"适应数据范围"由图标行的
  「原始谱图」按钮接管。
- `ClickableAxisItem`（继承 `pg.AxisItem`）：显式 `setAcceptedMouseButtons(Left|Right)`
  ——pyqtgraph 的 `AxisItem` 默认收不到鼠标按键，不设就点了没反应。
  - **左键**：循环到下一模式（X：2θ ↔ d 值；Y：计数 → 平方根 → 对数 → 计数）
  - **右键**：弹出模式菜单（当前项打勾），可直接跳任意模式
  - 两类轴都带 tooltip 说明当前模式与操作方式

#### ④ 谱图快捷图标行（`xinmatch/ui/plot_toolbar.py` + `plot_icons.py`）

参考姊妹项目 `D:\Project\XinRefinement` 的 `gui/plot_tools.py` / `button_icons.py` 移植：

| 按钮 | 动作 | 实现要点 |
|---|---|---|
| 原始谱图 | 恢复默认视场 | `reset_view()`：按**数据包围盒**设范围（见下方"踩坑"） |
| 横向框选 | 只改横轴，纵轴自动贴合该区间 | `RectMode` + 锁定 Y（`showAxRect` 处撑开矩形） |
| 纵向框选 | 只改纵轴 | `RectMode` + 锁定 X |
| 区域放大 | 横纵一起改 | pyqtgraph 默认 `RectMode` |
| 左移 / 右移 | 视场平移 25% | `pan_x(±0.25)` |
| 放大 / 缩小 | 以视场中心步进缩放（0.8×/1.25×），纵轴随之贴合 | `zoom_scale()` |
| 十字线 | 十字线 + 读数（读数同时贴谱图右上角显示一份） | 默认选中，保持改造前的既有体验 |

模式类按钮互斥但**允许再点一次取消**——因此不用 `QButtonGroup` 的 exclusive 模式
（exclusive 组不允许取消勾选）；瞬时按钮点完立即恢复未选中。

### 三、踩到的坑（都会复发，写进 HANDOVER §6）

1. **`RectMode` 不看 `mouseEnabled`。** 直觉做法是 `setMouseEnabled(y=False)` 让框选
   只作用横轴，但 `ViewBox.mouseDragEvent`（`ViewBox.py:1332`）在 `RectMode` 下直接走
   `showAxRect`，根本不读那个开关（它只影响平移）。→ 改成在 `showAxRect` 里把不参与
   缩放的轴换回当前视野，并且**锁定分支必须 `padding=0`**（默认 2% 边距会把被锁的轴
   一起撑开，锁定就白做了）。
2. **`clipToView=True` 让 `autoRange()` 只看可见点。** 曲线带 `clipToView` 时，
   `ViewBox.autoRange()` 只统计当前窗口内的数据 —— 缩放过一次之后，
   「适应数据范围 / 复位」就**再也回不到全量视野**（实测：设 20–30° 后 autoRange
   原封不动）。→ `reset_view()` 改为按 `data_bounds()`（对每条曲线的显示坐标求包围盒）
   直接 `setRange`，不依赖 autorange。
3. **`AxisItem` 宽度有两个真相。** `setWidth(w)` 设的是 `fixedWidth`（布局约束），
   `width()` 返回的是**当前几何宽度**；布局还没跑时两者不一致，用它做幂等判断会反复重设。
   → 比较 `fixedWidth`。
4. **模型 reset 未必发 `currentRowChanged`。** `set_candidates()` 换数据后"高亮行"已经
   无效，但 Qt 不保证补发信号；预览行会留在屏幕上指向不存在的相。→ 在
   `set_candidates()` 末尾显式发一次空信号。
5. **主题切换只刷视图会留一条浅色分区。** 主窗口原先把 `apply_theme_colors()` 直接打在
   `pattern_view` 上；本版改走 `pattern_panel`（视图 + 分区一起换色）。

### 五、关键设计决定

1. **参考线分区独立成 widget，塞进主谱图里当"负 Y 区"的方案否决了。** 后者能白拿
   横坐标对齐，但行高会跟着强度轴缩放——用户缩到弱峰区时整块分区跑出视野。
2. **行标签画在绘图区内，不用左轴刻度。** 用刻度就要把左轴加宽到能放下 `CaMg(CO3)2`
   这种式量，而左轴宽度必须与主谱图**相等**才能对齐——两个要求直接冲突。改用带底的
   `TextItem`：名字多长都不裁，且不占轴向空间。
3. **主谱图里原有的参考线（高度 = 声称贡献计数）保留。** 它与分区的语义不同：
   前者回答"这个相能解释多少计数"，后者回答"这相的线在哪、哪几条强"。用户说的是
   "**也**在这个区域都显示上"，没有要求撤掉原线条。
4. **按钮行不新增快捷键。** v1.3.1 的快捷键表已经排满（`shortcuts.py`），再加一组
   相近语义（缩放/平移）的组合键必然冲突；图标行的发现成本比快捷键低。

### 六、升级注意

- **无数据迁移**：`.xinDB` 库、`.xinm` 存档、`config.yaml` 全部兼容。
- **无 API 变更**：`core.*` 公开签名未动；`PatternView` / `PatternPanel` 既有方法
  （`add_pattern` / `patterns` / `fit_data_range` / `add_stick_pattern` …）全部保留。
  新增的只有视图操作方法（`reset_view` / `pan_x` / `zoom_scale` / `fit_y_range` /
  `set_plot_tool` / `x_display_of` / `left_axis_width`）与新模块。
- **界面变化**：顶部轴控制条不再显示。轴模式改到"点击坐标轴"（左键循环 / 右键菜单），
  「适应数据范围」= 图标行第一个「原始谱图」按钮。
- **二进制**：v3.6.2 的安装包 / 便携包**尚未构建**，等人工验收计划确定后再跑
  `tools/build_exe.ps1`（步骤见 HANDOVER §8.3）。
