# Report Printing

## Report Printing
There are several ways for printing the report:
- If the report is currently displayed, you can print it simply by clicking on the corresponding button  at the bottom of the report dialog.
- Alternatively (or if the report is currently not displayed), you can select the "Print..." command from the "File" menu, mark the "Report" option in the "Print" dialog
which opens, and press "OK". The "Print" dialog can also be opened by clicking on the corresponding button
in the main toolbar below the menu, or by pressing <Ctrl+P> on the keyboard.
- When you finish your phase analysis using the "Finish" command/dialog, simply mark the options "Report" and "Print" in the "Finishing actions" box at the bottom of the "Batch"-page of the "Options" dialog.
