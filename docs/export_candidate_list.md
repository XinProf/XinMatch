# Exporting Candidate List

## Exporting Candidate List
You can export the candidate list displayed in the upper part of the screen to a file.
Please select the "Candidate list" command from the "Export" submenu of the "File" menu, or open the context menu of the candidate list (right-click), and select the "Save list as..." command. Enter the file name and click "Save".
The following file formats are available:
- Text file (*.csv): ASCII tabular file
containing ';' characters as separators (a so-called "csv-file") which can e.g. be read by most spreadsheet or word processing programs
- PDF file (*.pdf)
- HTML file (*.html)
- Answer set file (*.mta)
