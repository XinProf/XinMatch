# Welcome to the Match! online help!

## Welcome to the Match! online help!
If you are new to Match! and would like to learn how to use the software, please start reading at the  chapter Match! Basics, and/or watch our tutorial videos on the web. For additional background information, please take a look at the manual (which can be opened using the menu command "Help/Manual").
For situations in which you would like to learn more about how to perform a certain operation or get more information about the background, there are two basic keyboard shortcuts to keep in mind:
- F1 (Cmd+? on the Mac) will open the online help at the index page, so that you can easily search for information about a given keyword/issue
- Ctrl+J (Cmd+J on the Mac) will display a table of all mouse operations and keyboard shortcuts that can be used.
Using these two shortcuts, you should be able to clarify most issues and questions.
If you are not familiar with phase analysis using powder diffraction data yet, you should read the chapters Match! Basics and Some General Hints for Phase Analysis using Powder, to get some basic understanding of the procedure.
If you have any questions or if you encounter problems, you will find help in the chapter "Support". Here you will also learn about the different ways you can contact us.
