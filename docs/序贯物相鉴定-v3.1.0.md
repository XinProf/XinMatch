# 序贯物相鉴定（v3.1.0）— 设计、判据与验收

> 版本：XinMatch v3.1.0（基线 v3.0.0）｜实现：`xinmatch/core/search/sequential.py` +
> `xinmatch/ui/main_window.py`｜测试：`tests/search/test_sequential.py`、
> `tests/ui/test_sequential_ui.py`

## 1. 解决什么问题

单次 search-match 只给一张排行榜。多相样品里主相强线一直主导 FoM：确认主相后重跑整谱
检索，前排仍是主相同族卡片，次相被压在 Top-20 之外。"已解释的峰"在旧流程里只能靠手工
从峰列表里排除，而且排除动作与候选卡片没有任何对应关系。

v3.1.0 把逐相确认做成闭环：

```
整谱检索 → 候选列表 → 选中一相并确认
        → 该相解释的峰从"待解释"里扣除
        → 用剩下的峰重新检索 → 得到"还剩下什么"的候选列表
        → 再确认 → 再检索 …（直到没有显著剩余峰）
```

## 2. 算法

### 2.1 三态峰

| 状态 | 判据 | 参与后续检索 |
|---|---|---|
| **已解释** | 扣除已确认相贡献后，残差 ≤ max(该峰自身观测强度的 5%, 全谱最强峰的 0.2%) | 否 |
| **未解释（剩余）** | 观测强度 ≥ 全谱最强峰的 1%，且残差高于上式阈值 | **是** |
| **低强度不计** | 观测强度 < 全谱最强峰的 1% | 否（也不算"已解释"） |

"低强度不计"这一档是实测逼出来的，不是拍脑袋：`synth_02`（SiO₂+CaCO₃）两相都确认后，
原本仍有 32/51 个峰"未解释"而强度已解释 92%——剩下的是噪声小鼓包（1–4%）；第三轮
检索于是把噪声匹配成 `Fe0.75V0.25` 这类垃圾候选。把它们单列一档后，第三轮直接返回空
列表（见 §5）。1% 是 search-match 的常规"最小强度"门槛。

### 2.2 逐相扣除与比例因子

对每个已确认相，在**计数域**用相关峰做最小二乘：

```
scale = Σ(I_residual,i · r_i) / Σ(r_i²)          r_i = I_ref,i / I_ref,max
contribution_i = scale · r_i                      (counts)
I_residual,i ← max(0, I_residual,i − contribution_i)
```

* `scale` 的量纲是 **counts / 单位相对强度**，所以"参考线高度 × scale"可以直接和实测
  峰高比较——谱图区的参考线条就是这么画的。
* **不能**复用 `CandidateResult.i_scale`：那是两侧各自归一化到 100 后的形状因子（理想值
  ≈1.0），量纲不对，拿来扣计数会把峰强算错数量级。
* 重叠峰（主相 + 未确认相）扣除后残差为正 → 留在剩余集合、强度按差值下调，不会被
  "位置撞上就算解释"吞掉。

### 2.3 整体重建（而不是增量更新）

`SequentialIdentifier` 的每个变更（`select` / `remove` / `undo` / `clear` / `reset`）都
从**原始峰列表**重算全部层：相关峰 → 比例因子 → 残差 → 掩码。原因：第 B 相的比例因子
是在 A 相扣完之后拟合的，**撤掉 A 必须允许 B 的数值改变**；增量更新会累积浮点漂移、
留下过期相关峰，撤销路径也写不干净。代价是每相一次相关性遍历（µs 级），换来的是
"状态 = f(原始峰, 相序列)"这条不变式（有测试 `test_rebuild_is_deterministic` 兜着）。

### 2.4 剩余峰检索

`search_residual(identifier, conn)`：

1. 取 `residual_peaks`（含残差强度）；
2. 调**同一个** `search_match()`（不是另写一套打分），因此 FoM 数值口径与整谱检索完全一致；
3. 剔除已确认的 `entry_id`（`exclude_matched=True`，默认）；
4. 把候选的 `pairs` 从"残差集合索引"映射回"原始峰索引"，GUI 才能正确高亮；
5. 额外返回 `n_residual_peaks / n_explained / n_ignored / covered_fraction` 供界面显示。

## 3. 界面

| 位置 | 内容 |
|---|---|
| 候选列表上方 | `确认该相（加入匹配列表）` / `撤销上一相` / `清空匹配列表` + 残差读数 `已确认 N 相 ｜ 剩余 X/Y 峰 ｜ 已解释 Z% 强度 ｜ K 个低强度峰不计` |
| 候选列表 | 双击、回车、右键「确认为匹配物相」、按钮，四种入口等价；已确认相自动从后续候选里剔除 |
| 匹配物相（Match List） | 确认动作填充；双击 / 右键「从匹配列表移除」= 回滚该相并重算 |
| 峰列表 | 「关联」列对已被确认相位置相关的峰打 ✓ |
| 谱图区 | 每相叠加一组参考线条（颜色与候选行同序），线高 = 该相声称贡献的计数 |
| 状态栏 | 确认后给"本相新增 X% 强度"；新增 < 1% 时提示"可能是重复条目或假相"；剩余峰检索在已解释 ≥90% 时提示"可以结束鉴定" |

FPFM 模式没有峰列表：首次确认时惰性按当前谱寻峰一次再进入序贯流程（状态栏提示）。
每次整谱检索（含「峰检测」、FPFM 检索）都会**重置**序贯上下文——新检索代表新一轮分析。

## 5. 验收二：真实库多相样品（默认 COD 无机库 71k，Cu Kα）

命令（见 §7）。脚本**自动**每轮取 Top-1 并确认，直到无候选——这是比人更"贪心"的用法，
用来暴露算法的下行边界。

| 样品 | 真相相 | 第 1 轮 | 第 2 轮 | 第 3 轮 | 真相相回收 | 确认真相相后覆盖度 |
|---|---|---|---|---|---|---|
| synth_02 | SiO₂ + CaCO₃ | **CaCO₃** ✓ | **SiO₂** ✓ | Ca₂KNb₃O₁₀（垃圾） | **2/2** | **95.5%** |
| synth_04 | Fe₂O₃ + SiO₂ | **SiO₂** ✓ | **Fe₂O₃** ✓ | Ni₀.₇Zn₀.₃（垃圾） | **2/2** | 81.2% |
| synth_12 | MgO + MgAl₂O₄ | **MgO** ✓ | **MgAl₂O₄** ✓ | Lu₀.₄Th₀.₆（垃圾） | **2/2** | 84.6% |
| synth_01 | Al₂O₃ + ZnO + CaF₂ | **Al₂O₃** ✓ | **CaF₂** ✓ | Ag₂O₃Te（垃圾） | **2/3**（ZnO 未召回） | 61.6% |

结论与边界：

1. **两相样品 3/3 在两轮内完整回收**，第 1 轮就把"最强相"定住，第 2 轮在剩余峰上定住次相
   ——这正是该功能要解决的场景。
2. **三相样品 2/3**：ZnO 从未进入第 3 轮 Top-3。这是基座引擎的召回/排序限制（与本次新增
   的序贯层无关——第 3 轮喂进去的就是干净的剩余峰），与 `docs/基准报告-物相检索-v1.md`
   里已登记的 NCM 811 召回问题同类，登记为后续项。
3. **不要自动驾驶**：真相相被确认后（覆盖度 80–95%），剩余峰多是卡片未收录的弱反射或
   噪声，此时排行榜前排会出现"凑巧命中两三个弱峰"的卡片（FoM 0.65–0.72）。因此：
   * 界面在覆盖度 ≥90% 时明确提示"无明确命中即可结束鉴定"；
   * 每相确认都会显示"本相新增 X% 强度"，新增 < 1% 时提示可能是重复条目/假相；
   * 每次确认都可撤销，没有不可逆操作。
4. **确认错相会"吃掉"真实峰**（残差是减法，没有自校验）：synth_01 的假相 Ag₂O₃Te 把覆盖度
   从 61.6% 抬到 73.8%。防线是三条可见证据：谱图区参考线条与实测峰是否吻合、本相新增
   强度、"关联"列打在哪些峰上；以及一键撤销。

```bash
# 单元 + 界面测试
python -m pytest tests/search/test_sequential.py tests/ui/test_sequential_ui.py -q

# 真实库多相样品（约 6 min，需 data/cod_inorganics.db 与 D:\Project\XRD\test_xrd\synthetic）
python - <<'PY'
import sqlite3
from pathlib import Path
from xinmatch.core.io import load_pattern
from xinmatch.core.peak.peak_search import find_peaks
from xinmatch.core.search.sequential import SequentialIdentifier, search_residual

conn = sqlite3.connect(r"D:\Project\XRD\XinMatch\data\cod_inorganics.db")
SY = Path(r"D:\Project\XRD\test_xrd\synthetic")
for name in ["synth_02", "synth_04", "synth_12", "synth_01"]:
    p = load_pattern(SY / f"{name}.txt")
    seq = SequentialIdentifier(find_peaks(p.two_theta, p.intensity),
                              wavelength=p.wavelength)
    for rnd in range(3):
        r = search_residual(seq, conn, top_n=10)
        if not r.candidates:
            break
        sel = seq.select(r.candidates[0])
        print(name, rnd + 1, r.candidates[0].entry.formula,
              f"cover={sel.covered_fraction:.3f}", f"left={sel.n_residual_peaks}")
conn.close()
PY
```

## 8. 参数一览（`core/search/sequential.py`）

| 常量 | 默认 | 含义 |
|---|---|---|
| `DEFAULT_EXPLAINED_FRAC` | 0.05 | 残差 ≤ 该峰自身观测强度的 5% → 已解释 |
| `DEFAULT_ABS_FLOOR` | 0.002 | 残差 ≤ 全谱最强峰的 0.2% → 已解释（防浮点尘） |
| `DEFAULT_MIN_PEAK_FRAC` | 0.01 | 观测强度 < 全谱最强峰的 1% → 不计入检索 |
| `DEFAULT_WINDOW_DEG` | 0.3 | 峰相关窗口（与 `search_match` 同口径） |

参数均为 `SequentialIdentifier(...)` 关键字参数，可按样品调整；GUI 目前用默认值。
