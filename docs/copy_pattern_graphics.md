# Copy Pattern Graphics

## Copy Pattern Graphics
In order to transfer the current pattern graphics to other programs like Microsoft Word or
Excel, you can copy it to the clipboard in Match! and paste it into the other program. In order to do so,
please press <Ctrl+C>, select the "Copy pattern graphics" command from the "Edit" menu, or select the
corresponding command from the diffraction pattern's context menu (which can be opened by right-clicking into it).
