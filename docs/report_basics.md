# The Report

## The Report
When you have finished the phase analysis of an unknown sample, you should view, export and/or print the so-called "report". The report is something like a summary of the phase analysis, including detailed information about
- the sample
- entries/phases selected as matching
- possible further candidates
- the search-match options you have used
- the restraints you have applied (if any)
- the peak list including the assignment of individual peaks to matching phases
- the integrals of various profile areas
- the residual peak intensities
Besides this, the diffraction pattern as it is displayed on the screen is included. The user can select which information shall be given in the report using the corresponding options.
In order to display the report, either select the "Report" command from the "View" menu, press the corresponding button  in the toolbar at the top, or press <Ctrl+R> on your keyboard (<Cmd+R> on the Mac). The report will be displayed in the panel on the lower right-hand side of the screen.
