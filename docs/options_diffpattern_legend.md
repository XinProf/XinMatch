# Options for the Legend in the Diffraction Pattern Graphics

## Options for the Legend in the Diffraction Pattern Graphics
In this window you can select if and how the legend in the corner on the upper right-hand side of the diffraction pattern graphics shall be displayed. It can be opened from the "Options" menu (command "Legend design"), or by pressing the corresponding button on the "Graphics" page of the "Options" dialog.
The following (display-) options can be set:
### Display legend
You can toggle the display of the legend in the upper right corner of the diffraction pattern using this option. It can also be adjusted directly using the  button in the diffraction pattern's context menu (which can be opened by pressing the right mouse button within the pattern graphics).
### Experimental pattern(s)
- File name: If you mark this checkbox, the name of the diffraction data file you have imported
is displayed behind "Experimental pattern:" in the legend of the diffraction pattern.
- Sample ID: You can display the sample ID (if present) defined in the diffraction data file you have imported behind "Experimental pattern:".
### Selected phases and reference entries
For matching phases (i.e. entries that are present in the match list on the right-hand side) as well as reference entries (i.e. entries that are currently marked in the candidate list at the bottom left), you can select to display the entry number, the formula sum, the name (e.g. mineral name), and/or the amounts, i.e. the result of the last quantitative analysis calculation (given in weight %).
If you mark the "Save as defaults" box in the corner on the lower left-hand side, you can make your selections permanent, i.e. they will be used next time you open Match!.
### Graphics Options
If you would like to modify other options and settings of the diffraction pattern graphics than the legend, you can do so on the "Graphics" tab of the "Options" window.
You can easily cancel the "Legend Options" window and display the "Graphics" options by pressing the "Graphics Options" button.
Note that this button is not available if the "Legend Options" windows has been opened already from within the "Options" window!
