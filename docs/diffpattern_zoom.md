# Zoom

## Zoom
If you get interested in a certain range of the diffraction pattern, you can enlarge this special range ("zooming"). There are several options for this:
- Just double-click at the position inside the diffraction pattern you would
like to investigate in further detail; Match! will zoom into the corresponding area.
Double-click again, and the display will return to the full pattern view.
- Just like in Match! version 1, you can select a certain area in the diffraction pattern graphics using the mouse, and Match! will adapt the graphics accordingly: Click the left button at the position where you would like to start selecting your zoom range (the mouse cursor will change to ), and keep it pressed while moving your mouse, until you have selected the desired zoom range, then release the button. Match! will focus on this area.
- Another option is to use the mouse wheel for zooming:
Move the mouse cursor to the region in the diffraction pattern
you would like to focus on, and turn the mouse wheel to focus
right into this area (or out again, if you turn the mouse wheel into
the opposite direction).
- Finally, you can use a dialog where you precisely define the range you would like
to view. In order to open this dialog, please select the "Define zoom area..."
command from the "View" menu.
Once you have zoomed more than once, you can return to the previous zoom by
pressing the right mouse button within the diffraction pattern and selecting "Previous zoom" from the context menu (or by selecting the corresponding command from the
"View" menu).
